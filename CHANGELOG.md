# Changelog

## v0.2.0 - Dockerized multi-service system

### Added
- Додано Dockerfile для сервісів `data_load`, `data_quality_analysis`, `data_research`, `visualization` та `web`.
- Налаштовано спільний запуск усіх сервісів через `compose.yaml`.
- Реалізовано локальний запуск усієї системи однією командою `docker compose up --build`.
- Додано файл `.env.example` для конфігурації середовища.
- Реалізовано окремий веб-інтерфейс для перегляду результатів через браузер.
- Оновлено дизайн веб-інтерфейсу у вигляді dashboard з вкладками.
- Реалізовано генерацію текстових звітів для модулів `data_quality_analysis` та `data_research`.
- Реалізовано генерацію графіків у модулі `visualization`.
- Організовано обмін результатами між контейнерами через SQLite та спільні томи.
- Реалізовано імпорт підготовленого CSV-файлу до бази даних SQLite.

## v0.1.0 - Initial release

### Added
- Створено базову структуру проєкту.
- Реалізовано модуль `data_load` для завантаження даних.
- Реалізовано модуль `data_quality_analysis` для перевірки якості даних.
- Реалізовано модуль `data_research` для аналітичного дослідження даних.
- Реалізовано модуль `visualization` для побудови графіків.
- Продемонстровано створення та розв’язання merge-конфлікту.
